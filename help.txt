Block size = 256 − last octet of subnet mask


Find block size
Jump in steps
Fit IP in range



Example =>  


````````````````````````````````````````````````````````````

Given:
IP: 192.168.1.10
Mask: 255.255.255.252
👉 Step A: Find Block Size
256 - 252 = 4

👉 So blocks go like:

0, 4, 8, 12, 16, ...
👉 Step B: Find Range

Your IP = 10

Closest lower block = 8

👉 So range:

8 → 11
👉 Step C: Final Answer
Type	Value
Network	192.168.1.8
Usable	192.168.1.9
Usable	192.168.1.10
Broadcast	192.168.1.11



``````````````````````````````````````````````````````````
